# PROJECT_RUYA

## Description

RUYA est une plateforme web développée dans le cadre d’un projet académique. Elle vise à offrir une solution numérique moderne permettant la gestion et le suivi des opérations bancaires et financières à travers une interface intuitive et sécurisée.

L’application est basée sur une architecture client-serveur utilisant Angular pour le frontend et Spring Boot pour le backend.

## Installation

### Backend

1. Cloner le dépôt :

git clone https://github.com/sirine5214/PROJECT_RUYA.git

2. Accéder au dossier backend :

cd backend

3. Installer les dépendances :

mvn clean install

4. Lancer l'application :

mvn spring-boot:run

### Frontend

1. Accéder au dossier frontend :

cd frontend

2. Installer les dépendances :

npm install

3. Démarrer l'application :

ng serve

4. Ouvrir dans le navigateur :

http://localhost:4200
